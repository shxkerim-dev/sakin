يومك مع الصلاة

الصلاة التالية وعدّ تنازلي حي وقوس تقدم. اسحب البطاقة الرئيسية للتنقل بين الصلوات القادمة والتواريخ. حساب دون إنترنت بعدة طرق، والعصر الحنفي أو المعتاد، وقواعد خطوط العرض العليا والمنطقة الزمنية وتعديلات الدقائق.

سماء تتبع يومك

يتبع المشهد الموقع المختار والوقت المحلي: الفجر والنهار والغروب والليل، وموضع توضيحي للشمس وقمر ذي سطح مفصل وطور حسب التاريخ. نجوم وسحب ومطر وثلج وضباب وتأثير الرياح عند توفر طقس نموذجي حديث. معاينات الوقت والطقس تغيّر المشهد فقط ولا تغيّر حساب الصلاة.

القبلة والمساجد

بوصلة القبلة ودليل المعايرة. ابحث ضمن 2 أو 5 أو 10 أو 25 كم، مع تجميع العلامات والتكبير بإصبعين وقائمة قابلة للتوسيع. اللمس يحدد المسجد ويعرض مساراً مضيئاً؛ والضغط المطوّل يفتح الاتجاهات والحفظ والمشاركة. إذا تعذرت خدمة الطرق يظهر دليل مستقيم بعلامة واضحة. بالقرب مني يستخدم موقع الهاتف المطلوب، ووضع المدينة يستخدم المركز المختار.

مظهر يناسبك

العربية والإنجليزية والروسية والأذربيجانية والتركية. بحث المدن بأبجديات متعددة، والأسماء المترجمة تتبع لغة الواجهة عند توفرها. مظهر فاتح أو داكن أو تابع للنظام أو غرافيت ثابت؛ وتحكم بالألوان وشدة السماء والرسوم وحركة البطاقات والميل الخفيف وتقليل الحركة. أداة مدمجة للشاشة الرئيسية تعرض الصلاة التالية والعد والتقدم ومواقيت اليوم.

التذكير والخصوصية

ذكّرني في الوقت أو قبله بـ5 أو10 أو15 دقيقة، بصوت النظام أو دون صوت، مع فحص الأذونات والتشخيص. لا حساب ولا إعلانات ولا حزمة تحليلات. الحساب وبحث المدن دون إنترنت؛ والطقس وصور الخريطة والبحث المباشر والمسار تتطلب الشبكة. تحتاج الدقة إلى أذونات Android. الاستمرار بعد الإشعار قبول لشروط الاستخدام؛ السياسة والتراخيص في الإعدادات ← المساعدة والتشخيص. المصادر: Adhan Java وGeoNames وOpen-Meteo وOpenStreetMap وGeoapify وGeoapify. تحقّق من الطريقة المحلية.
